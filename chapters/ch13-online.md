# Chapter 13: 「IMHO」：线上交流是好还是坏？

## Core Idea
数字技术究竟改善还是损害思考与写作水平？本书不站队，而是**要求你区分「线上交流」和「口头对话」——线上写作终究是写作，因此仍需书面表达的规范性**。

## Frameworks Introduced
- **线上交流的两种乐观论据**：① 接触的观点面空前广泛、获取信息即时，潜在知识量比过去扩大成千上万倍；② 把原本互不相识的人聚在一起，可以迅速发布、迅速获得反馈，还可以在自己的文本中插入指向他人观点的链接，读者点击即可看到——因此「通过回应他人展现自己思想」的建议同样适用于网络。
- **两种悲观论据（谷歌愚民／Facebook 失智）**：网络剥夺了学生思想表达的能力，碎片化使人难以深入。
- **反方的实证**：修辞学与文学创作教授安德烈亚·伦斯福德主持的「斯坦福写作研究」为期五年，报告指出当今学生「经常使用社交媒体，很擅长针对预期受众撰写信息」——也就是懂修辞学所说的 **kairos**：评估受众情况，采取针对性的语调和技巧，以便传达自己的观点。
- **核心警告**：线上写作的**即时性**（课程群、邮件、社交媒体）让它「好像成了口头对话」，于是我们很容易忘记：**它终究是一种写作形式**，因此往往需要体现书面表达的规范性。典型症状——收件人「一头雾水，因为谁都不记得她说过什么」。
- **回到本套技法**：既然线上是写作，就仍然需要归纳前文、阐明、引用、回应等能力；没有人会觉得论证技法是「小菜一碟」。

## Key Concepts
- **kairos（适时）**：修辞学的核心概念——针对特定受众与时机调整语调和策略。
- **书面表达的规范性**：即时性会降低记忆密度，因而提高「写清楚」的要求。

## Mental Models
- **线上不是电话**：它有书面的一切负担，却没有面对面的即时反馈。
- **把它当论文写**：线上发言也应有引述、界定、立场。

## Anti-patterns
- **把线上发言当随口聊天**：不归纳前文，读者回头找不到你的依据。
- **以为链接可以替代论证**：链接是导航，不是理由。
- **用「转发即同意」代替表态**：转发不是「我说」。

## Worked Example
书中的教学困境：有人在邮件里长篇陈述，收到的人「一头雾水，因为包括本人在内，谁都不记得她说过什么」。
问题不在内容质量，而在于**缺少书面规范**：没有标明在回应哪封邮件的哪一段，没有为其中的主张配上下文。

## Key Takeaways
1. 线上发言同样需要书面规范：引述、界定、立场一个都不能少。
2. 即时性提高「说清楚」的要求，而不是降低。
3. 用 kairos 意识调整语气：同一段话发给不同对象要改。
4. 转发不是表态，链接不是论证。
