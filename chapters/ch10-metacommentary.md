# Chapter 10: 「请不要误解我」：元评述

## Core Idea
文章是**连体婴儿**：正文负责亮观点，旁注负责解释。元评述就是那个辅助的另一半。

## Frameworks Introduced
- **元评述（Metacommentary）**：站在主文本旁边，替它解释含义、澄清误解、预告下文、连接各部分。
  - When to use: 需要防误解、防误读、防「我说的不是这个」时。
  - How: 写成与正文平行的补充句——「请不要误解我，我并不是在……」「这里所说的 X 指的是……」「换句话说……」「下面的例子将说明……」。
  - 适用条件：论点容易被误读、概念需要界定、结论需要被记住。
  - 失效边界：文本简单直白时，元评述是赘余。
- **元文本的四项职责**：① 把你真正主张的，与那些容易被误当成你的主张的说法区分开；② 预料并回应反对意见；③ 把各观点连贯起来；④ 说明你的主张在哪些地方还存在争议。
- **元评述的用途分类**：阐明含义（他说这句话的用意是什么）、引导读者跟上一个论证、预告后文论点、阐发论证进路、与其他可能混淆的观点划界。
- **发现自己的隐含推论**：理想情况下，元评述能帮你发现自己观点中起初没意识到的推论。
- **正文与元文本的互动**：波兹曼《娱乐至死》段落中的元评述，是站在主要观点一旁帮助读者跟上思路——主文本在讲，作者在旁白。

## Key Concepts
- **主文本 / 元文本**：前者提出观点，后者阐明正文含义。
- **画外音比喻**：元评述像电视剧解释剧中行为的画外音，或古希腊戏剧里向观众解释剧情的合唱队。

## Mental Models
- **连体婴儿**：主文本与元文本必须同时出生；只有主文本的论证读起来像自说自话。
- **预演读者的反驳**：写元评述时，假想读者会在哪一句产生误解。

## Anti-patterns
- **把元评述当免责声明堆砌**：写「当然，这只是我个人的看法」而没有具体澄清什么。
- **元评述与正文各说各话**：元文本引入的概念与主文本不一致，读者更困惑。
- **用元评述代替证据**：澄清措辞不能替代论证。

## Worked Example
需要澄清的典型场景：读者会把你的「反对」误读为全面否定。
- 弱：「当然，以上只是从某一角度出发的看法。」
- 强：「请不要误解我：我反对的不是这项技术本身，而是把它部署在缺乏审核机制的场景中——同样的技术，配上前置审核，我完全支持。」

## Key Takeaways
1. 凡是需要防误解的地方，就写元评述。
2. 元评述要具体：澄清哪一句话的哪个意思。
3. 写完回读一遍，标出所有「当然」「也就是说」，看它们是否真的在澄清。
4. 元评述能逼出你自己没意识到的推论。
