# Chapter 9: 「我觉得不行／缺乏可行性」：学术写作不等于别扭

## Core Idea
生僻的学术语言与日常语言之间**不必二选一**。别扭不是严谨的代价，学术对话应该接纳更多人。

## Frameworks Introduced
- **高低搭配（Say It Two Ways）**：用学术说法讲完，再用日常说法复述一次。
  - When to use: 关键概念首次出现、核心结论需要被记住时。
  - How: 学术表述后紧跟一句白话——「换句话说，……。」「说得更直白，……。」
  - 适用条件：读者可能不熟悉你的术语。
  - 失效边界：正式数学证明、精确术语定义、代码/公式密集处，白话复述会稀释精度。
- **风格混搭看你面向谁**：什么时候该阳春白雪、什么时候可下里巴里，取决于**受众与目的**；书中给出的判准是：面向专家用标准书面语，面向更广受众时适度口语化，并把混搭当作「语言习惯语言习惯本来就该放宽，讨论的大门才不会被术语关上」的主张来用。
- **没有金科玉律**：写作有无数种选择，选词句时不必拘束，「高一点的说法和低一点的说法并不冲突，用着顺手就行」。
- **等义替换的两端**：正式一点可用「没有注意到」而非「从鼻子下面溜走了」；接地气一点可用「脑子开小差了」而非「忽视了」。
- **不排斥带色彩的词**：书中示范了一位学者在标准书面语中嵌入口语（甚至拼写变化）以表达其主张的现象，并据此指出语言习惯应当开放。

## Key Concepts
- **学术对话的门槛**：用生僻语言并不抬高门槛，只把一部分读者挡在门外。
- **准确性优先于文采**：如果口语化会牺牲准确性，就不牺牲；这是「让严谨与好懂兼得」的顺序。

## Mental Models
- **给同一个观点两副外壳**：一副精确，一副好懂，按读者取用。
- **把别扭当作警报**：读起来别扭，通常是作者自己没想清楚，而不是术语的错。

## Anti-patterns
- **把生僻当成学术性**：用大词掩盖没想通的部分。
- **用「别别扭扭」冒充严谨**：「本文认为该现象具有相当程度的……」这类空转表述。
- **一刀切**：要么全用术语、要么全用口语，两种极端都不是本书的主张。

## Worked Example
一位译者把学术腔译成直白说法：「不用怀疑，这个人就是控制不住自己。」
作者的评价是：这提供了「高低搭配」的简单方法——学术语言说一遍，日常语言再说一遍，这是突出要点的好办法。

## Key Takeaways
1. 关键结论给两种表述。
2. 混搭的尺度由受众和目的决定，不由「学术规范」决定。
3. 别扭的句子通常是你没想清楚，先修逻辑再修语言。
4. 「我觉得不行」不是风格问题，是准确性问题。
