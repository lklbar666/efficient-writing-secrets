# Chapter 8: 「因此」：通顺连贯

## Core Idea
难读的文字，几乎都是因为作者**既不交代这一句接住了上一句的什么，也不预告它会把读者带向哪里**。作者以为写作是「想到哪儿写到哪儿」，读者却要自己猜每个句子从哪来、往哪去。

## Frameworks Introduced
- **每句两只手**：一句话同时向后伸（承接前句）与向前伸（预告后句）。
  - When to use: 写完每一句都检查一次。
  - How: 写下一句前问自己：它承接了上一句的什么？它给下一句留了什么？
  - 适用条件：所有连续成篇的文字。
  - 失效边界：清单、表格、诗体断行刻意不连贯。
- **自己动手原则（Do It Yourself）**：连贯性要作者在写作时解决，不能把问题抛给读者。
- **四种衔接手段**：
  1. **连接词**（transition）：延续（换句话说、实际上）／加入新内容（此外）／举例（例如）／推论（因此、于是）／限定修正（但是）／比较（与此类似）／补充（而且、事实上）。
  2. **指示词**：这个、这样的、上述、该。
  3. **为文章设定一组关键词**：让「我说」与「他说」共享同样的关键词，是两者关系紧密的最可靠办法。
  4. **换一种说法复述**：改变表述以避免赘余。
- **作者的三种常见病灶**：
  - **话题统一但关系缺失**（小杨式）：每句都在谈阿福，但从不说清两句什么关系。
  - **话题突变**：句内或句间突然换话题。
  - **决不回头看**：从不重读自己写完的句子，把写作当成堆积资料。

## Key Concepts
- **连接词的功能分类**：读者靠它知道你是延续、加入、举例、推论还是修正。
- **复述（换句话说）是承认**：说明你要重述前文，而不是继续推进。

## Mental Models
- **两只手**：每句向后握一次、向前握一次，读者就不会掉线。
- **自己动手**：不要指望读者替你补连接。

## Anti-patterns
- **话题统一≠连贯**：都在谈同一个主语，句子之间仍可能毫无关系。
- **攒到最后再通读**：小杨从不回头看。写作与阅读是同一件事。
- **只堆信息不建论证**：作者以为写作是把资料和见闻堆在一起，而不是搭出一条连贯的论证线。

## Worked Example
小杨式句子：
> 阿福是一台旧机器。每个零件都松了。

问题不在话题（都是阿福），而在两句之间没有任何关系标记。改法之一是加转折或让步（「但是」「即使」），但原书指出：加连接词并不解决根本问题——**根本问题是作者没有想清楚两句话为什么相关**。真正的修法是先想清楚：零件松与「好狗」这个判断有什么关系？再决定用「但是」还是「即使」，或干脆把两句拆开、各自成段。

## Key Takeaways
1. 每写完一句，检查它有没有「两只手」。
2. 连接词不是装饰，它在向读者报出你这一句的功能。
3. 让「我说」和「他说」共享关键词，是防止二者脱节最省力的办法。
4. 写完必须重读——把写作和阅读当成同一件事。
5. 「决不回头看」的作者，句子之间必然没有连接。
