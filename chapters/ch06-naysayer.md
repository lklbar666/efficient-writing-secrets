# Chapter 6: 「有人可能会反对」：加入反对者的角色

## Core Idea
**主动写出反对意见会提高而非降低你的可信度**：你自己谈的批评越多，批评者手里的武器越少；你越能给出令人信服的回答，就越强。

## Frameworks Introduced
- **预料反对意见（Naysayer）**：设想随着论证展开，别人可能会说什么，并把它写进文本。
  - When to use: 任何有说服意图的写作；尤其是你正要做重要主张时。
  - How: 用模板引入「然而，有些读者可能会反对我的观点，坚持认为……」或「当然了，许多人可能会表示反对，理由是……」。
  - 适用条件：你的主张有争议，或读者很可能想到某个反对。
  - 失效边界：纯事实陈述、事务性通知（预算排期）不需要。
- **给反对者贴标签**：把反对意见归于某个意识形态或流派（「许多女性主义者可能会反对说……」「社会达尔文主义者当然会提出……」），文章更精准、更有分量。
  - 配套的防刻板印象手段：**加限定**（「虽然基督徒的想法并非全都一样，但其中一些很可能会反驳我的论点……」）、**慎选标签**（用「公益律师」代替「律师」，用「定量社会学家」代替「社会学家」）。
- **非书面语引入反对意见**：用提问代替陈述（「但是，我的提议有现实意义吗？」），或让反对者直接开口（「『不可能，』有些人会说，『你对这项研究的解读是有选择性的。』」）。
- **内心中的「有疑者」**：反对者可以是自己——作家简·汤普金斯描述的写作中途惊醒、意识到自己忽略了某条批评的体验。切尔尼在书里设一章「有疑者」，让反对意见占据整整一段，而不是一笔带过。
- **为什么要做**：① 你的批评者能用的武器更少；② 显得对读者尊重（不把读者当轻信人言的傻瓜）；③ 塑造向论辩开放的自信；④ 不写反对意见，你可能发现自己其实没什么好说的。

## Key Concepts
- **反对意见不只来自外部**：自己的未解决疑虑也是「他说」。
- **不点名 vs 贴标签**：不点名（读者、许多人）适用范围广；贴标签更精准，但要防刻板印象。

## Mental Models
- **料敌先机，先发制人**：探讨反论是一种先发制人的手段。
- **把反对者当成你请来的同伴**：给他一段篇幅，让他在你文本里说话。

## Anti-patterns
- **用回避代替策略**：怕冲突而只字不提，读者会自己补上批评并怀疑你。
- **把反对者写成稻草人**：贴标签却不加限定、也不给反驳空间，读者会认定你在树敌。
- **一笔带过反对意见**：反对者刚出场就被驳倒，反而显得你心虚。

## Worked Example
杰克逊《想抽烟？去汉堡》写法：直接让「反吸烟者」开口——
> 「忍忍吧，」反吸烟者说，「你们只是少数人。」我本来以为，大城市能容下各种各样的少数人呢……「吸烟会害死你的。」他们说。

引号让谁说了什么一目了然，读者看见的是一场对话，而不是作者转述的反对意见。

## Key Takeaways
1. 每篇有说服意图的文章至少要有一处「有人可能会反对」。
2. 反对者可以是具体的（有标签），也可以是「读者/许多人」，但后者更保险。
3. 给标签必须加限定或慎选标签，否则就是制造刻板印象。
4. 用提问和直接引语引入反对意见，比陈述更自然。
5. 写下你内心那个「有疑者」，通常会逼出文章真正的论点。
