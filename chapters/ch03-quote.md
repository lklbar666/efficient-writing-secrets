# Chapter 3: 「如他所述」：引用之道

## Core Idea
引用原文能大幅提高客观性与可信度，但**引用最大的问题不是太少或太多，而是不言自明**——作者以为读者也懂，于是把引文往正文里一扔就跑了。

## Frameworks Introduced
- **引用三明治（Quotation Sandwich）**：引文上下各夹一层。
  - 顶上那片面包 = **引用声明**：写清原文作者、设定语境（谁、哪本书、什么主张）。
  - 底下那片面包 = **后续说明**：解释引文含义，并说明它与正文论点如何相关。
  - 适用条件：任何直接引语，尤其是长引、争议人物的引文。
  - 失效边界：纯转述性的短引（一个数据、一句定义）不需要完整三明治，套用反而臃肿。
- **引文要相关**：选引文的标准是「它能支持我这一段的哪个具体主张」，不是「它好看」或「它权威」。
  - 特别注意：写作是往复过程，正文焦点移动后，原先合适的引文会失去意义，选引文与推进论证是往返而非直线。
- **孤悬引文 / 「逃逸」引文**：引文孤零零悬在那里，没有作者、没有解释、没有关联——像撞了坑却逃之夭夭的司机。
- **正文与引文要糅合**：后续说明不是复述引文，而是在呼应的基础上把论证引向自己的方向。
- **过分解读？**：没有固定法则，读者越难理解的引文越需要配套。原则是：**有疑问就先写上**——多解释几句总比读者一头雾水强。争议人物的语言尤其需要你说明自己是怎么解读的。

## Key Concepts
- **引文像孤儿**：从原语境抽离、嵌入新语境；两个语境之间的桥必须由你搭。
- **引用声明与后续说明**：前者「代其立言」，后者「代其释义」。

## Mental Models
- **把引文当成需要照顾的客人**：介绍它、安置它、然后送它回家（接回你的论点）。
- **读者需要知道你怎么读**：语言可被用来支持相反的论点，你不说明解读，双方认知就可能错位。

## Anti-patterns
- **引用忌讳·冗余**：「奥威尔提出了一个想法」——直接写「奥威尔提出」或「奥威尔的想法是」。
- **引用忌讳·误导**：「莎士比亚的一段引文说道」——暗示引用者是莎士比亚；引用者是你。
- **掉书袋**：选一段与本段论点无关的名句插进来。
- **只引不评**：大段引文后立刻转移话题，读者无法重构作者论点。

## Worked Example
失真版：「苏珊·博尔多针对女性节食问题写道：『……62% 的受调查女孩说自己在节食。』」——然后紧接「我认为博尔多是对的。她的另一个观点是……」

问题：没说博尔多是谁、这话与作者观点什么关系、她「对」在哪里。

合格版：先点明身份与立场（女性主义哲学家博尔多谴责道……），再把引文与论题绑定（西方对节食的过分推崇正向世界最偏远的角落蔓延），引文后接两段解释，最后才用自己的话展开——引文从「干巴巴的统计数字」变成「定量例证」。

## Key Takeaways
1. 每段直接引语都套三明治；至少要有底下的面包。
2. 选引文的标准是「支持本段哪个具体主张」，其余一律不选。
3. 后续说明要往你的方向引导，而不是重复引文。
4. 读者可能误读，尤其是争议人物——说明你的解读。
5. 「X 的一段引文」这类表述既冗余又误导。
