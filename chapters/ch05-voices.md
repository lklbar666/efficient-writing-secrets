# Chapter 5: 「然而」：区分「我说」与「他说」

## Core Idea
读者必须随时知道**哪个声音是作者的、哪个是作者在转述的**。缺失这个标记，「他们都说 X」会被读成「作者认为 X」。

## Frameworks Introduced
- **声音标示语（Signaling Voices）**：用词汇与句法把「他说」和「我说」分开。
  - When to use: 段落里出现转述、概括、他人观点时。
  - How: 转述段用「据 X 的说法」「人们普遍认为」；转向自己时用「然而」「但我以为」「我的看法是」；用直接引语加引号让人物自己开口。
  - 适用条件：有第三方观点出现在你的文字中。
  - 失效边界：整篇都是你自己的话时，标示语是噪音。
- **「然而」的转折分界**：在两段之间放一个明确转折词，读者立刻知道声音切换了。作者用曼特西奥的文本示范：第二段以「然而」开头 + 前后构造对照 + 采用断言式语调，三者叠加完成切换。
- **第一人称「我」是可以用的**：常见说法是学术写作应当避免「我」，本书明确反对这种教条——扎实的论点取决于论证与论据，不取决于用不用代词；而且若坚持不用第一人称，区分「他说/我说」这个关键技法本身就会变得困难。
- **「我不认为」优于「我认为」**：以否定式表态，读者更容易接受，同时不显得傲慢。

## Key Concepts
- **腹语术（ventriloquism）**：模仿他人说话而不表明身份，是学术阅读中最常见的误读来源。
- **声音标示语也是阅读工具**：读懂它们，才能还原作者与谁在争。

## Mental Models
- **在两段之间放一扇门**：转折词是门，读者穿过它就知道换了个人在说话。
- **把「我认为」看成一枚图钉**：它把你的观点钉在文本里，读者不会错认。

## Anti-patterns
- **删除声音标示语**：从原文转述中把「据说」删掉，原本「作者反对的观点」立刻变成「作者的观点」。
- **用第一人称代替论证**：「我认为」后面必须跟理由。
- **把转述压成没有来源的断言**：「研究表明……」而没有是谁研究。

## Worked Example
曼特西奥原文两段：第一段陈述「我们都是中产阶级」，第二段以「然而」开头断言「阶级分化是真实的」。

教学场景：学生总以为「我们都是中产阶级」是曼特西奥自己的立场——他其实在用腹语术模仿他人，文中并无声音标示语时，读者就分不清哪段是他的信念、哪段是他反对的观点，甚至看不出两段互相矛盾。

## Key Takeaways
1. 每一个转述都要有来源标记，每一个自己的观点都要有归属标记。
2. 段落之间换声音时，明确用「然而」「但是」「换句话说」。
3. 「我」可以用，但「我」后面必须接论证。
4. 校对时专门检查一遍：把标示语遮住，读者还能分清谁在说话吗？
