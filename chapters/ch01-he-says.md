# Chapter 1: 「他说」：引述为先

## Core Idea
有说服力的论证不是凭空立论，而是**先交代你正在回应谁**，再提出自己的看法。作者把这一动作称为这本书全部技法的「DNA」。

## Frameworks Introduced
- **引述为先（Enter the Conversation）**：尽早给出「他说」的归纳，并在全文关键处反复提醒读者。
  - When to use: 任何非纯叙事的写作——评论、论文、报告、邮件、对外说明。
  - How: 开篇一段说清「大家通常认为 X……但有人指出 Y」，紧接着给出自己的判断；中段用回顾句锚定。
  - 适用条件：议题本身存在争议或既有说法。
  - 失效边界：纯事实通告、内部备忘、新闻快讯中没有「他说」可引；硬引一个不存在的共识会显得做作。
- **回顾句（Signposting）**：在论证推进到新环节时，用一句话把读者带回缘起：「如前所述，X 的支持者不能同时保留……」。文章越长越需要。
- **五种引述入口**：
  1. 引述他人观点：「最近，许多学者认为 X 存在若干重大缺陷。」
  2. 引述标准观点（挑战思维定式）：「传统观点认为……」「常识告诉我们……」
  3. 以你说为他说：回应的「他说」可以是你自己过去的看法，或你现在怀疑的看法。
  4. 引入假定或推论：指出对方**没有明说**但默认为真的前提。
  5. 引入争议：摆出两到三种对立说法，亮出自己的立场。
- **次序的两难**：延迟交代「你在回应什么」会打乱读者的理解次序，也打乱作者自己的思考次序——没有人会先写完一篇为 X 辩护的文章，然后才偶然看到对 X 的批评。

## Key Concepts
- **对话性写作**：优秀写作就是与他人对话；学术写作尤甚，作者不仅要表达自己，还要回应前人的论述。
- **开宗明义 vs 引述为先**：两者不矛盾。中心论点不能太晚，但必须说明自己是在支持、反对、修正、深化还是检验他人观点。
- **模板的价值**：模板把注意力从「想什么」转到「怎么组织想法」，让写作者意识到有些重要技法从未被教过。

## Mental Models
- **把作者想成在咖啡馆争论，而不是在空屋独白**：他在回应某些人，也在说服某些人。
- **把「他说」当成一篇文章的坐标原点**：没有这个原点，读者无法定位你的位置。

## Anti-patterns
- **只讲自己**：通篇自说自话，等于宣称「此事无须论证」——这正是本书要打破的信念。
- **过度引述**：花大半篇幅列举批评而始终不提自己的立场，读者会问「你讲这些干什么」。
- **把解释推迟**：先写自己的观点、最后才补「有人在反对」，是顺序上的失败。

## Worked Example
一位社会学家在会议上花了四十分钟讲 X 博士的成果，结束时听众仍不明白他为什么讲这个——原来该领域早已有多人激烈质疑 X 博士，发言人正是回应这些批评。

**改法**：开篇即写「X 博士的著作在社会学界颇受推崇，但 Y 与 Z 最近尖锐批评其证据基础薄弱」；随后给出「因此我认为……」；中段插入回顾句「如前所述，X 的支持者无法解释为何……」。

## Key Takeaways
1. 写之前先问：**我这一篇在回应谁？** 答不上来，说明这个题目还没准备好。
2. 「他说」要在开篇、转折处、结尾至少各出现一次。
3. 归纳他人观点不能少于一句，否则读者无法独立评价。
4. 引入争议比单方面立论更可信，但争议必须在两段之内交代完。
5. 写完通读一遍，标出所有「他/他们/有人认为」，检查它们是否都有出处。
